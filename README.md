# st_high-school-2g10c
# (룰루랄루) — (지역별 공공화장실의 공간적 분포와 접근성에는 어떤 차이가 나타나며, 이러한 차이로 인해 화장실 이용에 어려움을 겪는 접근 취약지역은 어디인가?)

## 팀원
- 21023 이준서
- 21013 김규민
- 21011 최서현 

## 주제
공공화장실의 공간적 분포 불균형에 따른 접근 취약지역 및 생활 편의시설의 사각지대 분석

## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단.
- 21023 이준서: 저는 지역마다 공중화장실의 수와 분포에 차이가 있다는 점에 관심을 가졌습니다. 특히 인구가 많은 지역이나 면적이 넓은 지역에는 화장실이 충분히 설치되어 있는지 궁금해졌고, 지역별 화장실 수를 비교해 생활 편의시설의 차이를 알아보고자 이 주제를 선정하였습니다.
- 21013 김규민: 저는 지역마다 공중화장실의 설치 수와 분포에 차이가 있다는 점에 관심을 가졌습니다. 공공데이터를 통해 지역별 공중화장실 현황을 비교해 보면 화장실이 상대적으로 부족한 지역을 찾을 수 있을 것이라고 생각했습니다. 이를 통해 실제로 어느 지역에서 공중화장실을 이용하기 어려운지 알아보고자 이 주제를 선정하였습니다.
- 21011 최서현: 저는 공중화장실이 일상생활에서 꼭 필요한 시설이지만 지역에 따라 이용하기 어려운 정도가 다를 수 있다는 점에 관심을 가졌습니다. 지역별 인구수와 면적에 비해 공중화장실이 얼마나 설치되어 있는지 비교하면 화장실이 부족한 지역을 파악할 수 있을 것 같아 이 주제를 선정하였습니다.

## 방법
-회귀분석:인구수와 지역 면적이 공중화장실 개수에 어떤 영향을 주는지 알아보기 위해 회귀분석을 선택했다. 인구와 면적을 이용해 예상 화장실 수를 계산하고 실제 화장실 수와 비교하여 상대적으로 시설이 부족한 지역을 찾아보고자 한다.

## 분석 과정
1. 데이터 수집: 공공데이터포털과 KOSIS에서 공중화장실, 주민등록인구, 지역별 면적 데이터를 수집한다.
2. 변수 선택: 인구수와 면적을 독립변수, 공중화장실 개수를 종속변수로 설정한다.
3. 전처리: 주소에서 시군구를 추출하고 행정구역 이름을 통일하며 중복 및 결측값을 확인한다.
4. 분할: 데이터를 학습용 80%, 테스트용 20%로 나눈다.
5. 기준선: 모든 지역을 학습 데이터의 평균 화장실 개수로 예측하는 평균 모델을 사용한다.
6. 후보 모델 비교: 선형회귀와 랜덤포레스트 회귀를 비교한다.
7. 선택: 테스트 데이터에서 예측 오차가 더 작은 모델을 선택한다.
8. 평가: MAE, MSE, R²를 사용한다.
9. 해석: 실제 화장실 개수와 예측 화장실 개수를 비교하여 부족할 가능성이 있는 지역을 찾는다.
10. 한계 점검: 관광객, 유동인구, 개방시간, 실제 이동거리 등이 반영되지 않았다는 점을 확인한다.
