## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단.
- 21023 이준서: 저는 평소에 날씨가 더울 때는 아이스크림을 자주 사 먹고, 추울 때는 거의 먹지 않습니다. 그래서 저의 개인적인 경험처럼 실제로 기온이 상승할수록 사람들이 아이스크림을 실제로 얼마나 더 많이 구매하는지 구체적인 수치로 확인해 보고 싶어 이 주제를 선택하였습니다.
- 21013 김규민: 저는 막연히 '더우면 많이 팔리겠지'라고 생각하기보다, 기온 데이터를 분석해서 실제로 매출에 얼마나 큰 영향을 주는지 직접 증명해 보고 싶었습니다.
- 21011 최서현: 저는 우리 주변에서 흔히 볼 수 있는 날씨와 소비 데이터를 연결해 보면 데이터 분석 과정을 훨씬 쉽게 이해할 수 있을 것 같아서 이 주제를 선택했습니다.

## 방법
-회귀분석:인구수와 지역 면적이 공중화장실 개수에 어떤 영향을 주는지 알아보기 위해 회귀분석을 선택했다. 인구와 면적을 이용해 예상 화장실 수를 계산하고 실제 화장실 수와 비교하여 상대적으로 시설이 부족한 지역을 찾아보고자 한다.

## 분석 과정
1. 데이터 수집: 공공데이터포털과 KOSIS에서 공중화장실, 주민등록인구, 지역별 면적 데이터를 수집한다.
2. 변수 선택: 인구수와 면적을 독립변수, 공중화장실 개수를 종속변수로 설정한다.
3. 전처리: 주소에서 시군구를 추출하고 행정구역 이름을 통일하며 중복 및 결측값을 확인한다.
4. 분할: 데이터를 학습용 80%, 테스트용 20%로 나눈다.
5. 기준선: 모든 지역을 학습 데이터의 평균 화장실 개수로 예측하는 평균 모델을 사용한다.
6. 후보 모델 비교: 선형회귀와 랜덤포레스트 회귀를 비교한다.
7. 선택: 테스트 데이터에서 예측 오차가 더 작은 모델을 선택한다.
8. 평가: MAE, MSE, R²를 사용한다.
9. 해석: 실제 화장실 개수와 예측 화장실 개수를 비교하여 부족할 가능성이 있는 지역을 찾는다.
10. 한계 점검: 관광객, 유동인구, 개방시간, 실제 이동거리 등이 반영되지 않았다는 점을 확인한다.
